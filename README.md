# Pubquizzz & Spellenkast

Pubquiz-app **plus een Spellenkast met 10 party-games** (groot scherm = spel, telefoon = controller).
Draait volledig in de browser via **GitHub Codespaces** — geen terminal, geen installatie.

**Spellen:** Fladderfeest · Eierbommen · Doolhoftikker · Vier op een Rij · Slangenkuil · Tankslag · IJs-Sumo · Kleurreflex · Hordenrace · Meteorenregen

## Starten
1. Klik op de groene knop **Code** → tabblad **Codespaces** → **Create codespace on main**.
2. Wacht ± 1–2 minuten. Het bestand **START-HIER.md** opent met de links.
3. **Spellenkast:** open de link *Spellenkast* op de tv. **Pubquiz:** open *Beamer* op de tv en *Host* voor jezelf.
4. Spelers scannen de QR-code op de tv met hun telefoon.

## Stoppen
Ga naar https://github.com/codespaces → bij je codespace **⋯** → **Stop codespace**.
(Volgende keer: daar op dezelfde codespace klikken om hem weer te starten.)

## Tip
Zet vooraf op https://github.com/settings/codespaces de **Default idle timeout** op **240 minuten**,
anders stopt de codespace na 30 minuten zonder activiteit.
